# Proteomic-ADdataset
“Developed a  pipeline for proteomic datasets' analysis to identify Alzheimer’s disease-related pathways”

Overview 

Proteomics data were obtained from a publicly available Alzheimer’s disease meta-analysis dataset, specifically the Unwin et al. cohort (entorhinal cortex and hippocampus), which provides normalized protein abundance values for AD and control samples.

Datasets
• Proteomics: GSE29652 (brain proteomics)
Two files, forming the whole analysis dataset, were obtained from a github repository (https://github.com/hazhay/Meta-analysis_AD/tree/main/Data)

Methods

Single-modality analysis
•	Normalization and preprocessing  
•	Differential abundance (proteomics) 

Motivation

This project was developed to build expertise in proteomic datasets demonstrate the ability to combine heterogeneous biological datasets.
